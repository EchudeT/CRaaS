## 保留的实现差异

- 当前额外保留链路速率 `bandwidth`，与接口、协议分开记录。
- 当前保留具有不同语义的平行关系，避免参考中按相同显示文字去重可能丢失关系的问题。
- 当前逻辑节点不自动填入参考中的演示 CPU/内存/磁盘或镜像占位配置；未映射资源前禁止部署。
- 参考整站还有账号/租户管理、工作负载调度决策、审计、模拟部署记录、虚拟机监控和旧接口兼容。这些与真实平台部署接入均不在本次“三类场景严格抽取及数据展示”范围内，不能声称已经逐项复刻整个容器。
- 资源计数以当前数据库及场景关联计算，类型目录与已部署设备分开展示。

在上述范围内未发现必须补充的参考功能。后续真实部署需要平台 API、镜像、规格、网络和权限映射，不能以离线示例代替。
