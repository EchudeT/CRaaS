# 三类场景数据展示

本次补充场景模板、实体目录、场景关联的资源/实例/监控；首页与严格抽取提示词保持原样。

## 页面入口

- `/templates`：每类两个可直接打开的完整逻辑示例，支持场景、业务和关键词筛选。打开后可看拓扑、数量展开、设备属性、接口、关系以及完整原文与证据；无需模型配置。
- `/entities`：浏览全部 156 类实体，支持场景、类别、名称/ID/别名检索。类型目录不等同于已部署设备。
- `/resources`：按场景展示数据库中已关联的镜像、计算、存储、网络资源，计数来自当前数据。
- `/instances`：每类一个离线演示实例，可跳转来源模板、对应场景资源与监控。演示实例未执行部署，没有登录凭据或真实资源句柄。
- `/monitor`：按相同场景聚合计算节点，并列出关联实例。指标分别标注演示、模拟、真实采集、采集失败后的模拟值。历史图独立标记来源。

页面通过 `?scene=<scene_id>` 保留筛选条件，场景栏可跳转其他关联页面。

模板编辑器使用左侧节点图标栏：搜索或按类别筛选后，将图标直接拖到画布添加。落点会按画布缩放和平移换算，落在分组内时归入该分组；新节点自动选中，可在右侧修改名称、数量、区域及原文依据。双击图标或聚焦后按回车也可添加。逻辑模板组件来自主场景及已有次场景的实体目录，通用模板展示基础设备类型。节点记录“手工添加”来源，不自动补线、编造证据或指定部署资源；保存后保留位置和来源。JSON 编辑器放在下方折叠区。

| 场景 | 示例 | 数据来源 |
| --- | --- | --- |
| 通信网络及服务 | 5G接入与核心网、IMS语音与策略控制 | CNS-TR-001、CNS-TR-101 |
| 新型数据中心网络及服务 | POD互联与计算、管理网与带外管理 | NDC-TR-001、NDC-TR-101 |
| 新型城域网及服务 | 无线接入与承载、城域承载与服务 | MAN-TR-001、MAN-TR-101 |

示例直接取自仓库已有的 `backend/app/assets/topology/examples.json` 训练示例；实体目录来自同目录的 `catalog.json` 和 `categories.json`。未将测试集答案作为运行时数据，也不调用参考工程的服务或 Docker。

这些示例用于展示已有数据与抽取结构，不是运营商实际部署方案；原有示例内容保留原样。它们仍为逻辑拓扑，未填写镜像、规格和真实网络映射，部署入口继续禁用。

## 来源与关联

`resource_contexts` 是新增的独立表，用于记录资源类别、资源 ID、所属场景列表及来源；无需修改旧资源表结构。模板的场景与演示标记保存在拓扑 `meta`，实例保存自己的场景快照和演示标记，不随模板后续编辑改变。

资源来源含义：

- `demo`：系统预置演示记录，不能通过修改关联伪装为真实资源。
- `registered`：人工录入或旧记录，页面提示“来源待核验”。
- `synced`：通过资源驱动同步的记录，仅表示数据来源，不表示已完成部署。

真实资源准备好后：

1. 按已有方式配置 CMDB/平台资源同步，或在资源列表录入镜像与计算节点。
2. 在对应资源列表点击“关联场景”，选择一个或多个场景。
3. 取消演示资源的场景勾选，新页面的资源计数和节点监控随关联更新。取消关联不删除或迁移任何资源。
4. 真实部署实例由执行器创建时保存模板所属场景；离线演示实例只作展示，不会变成真实部署实例。
5. 配置 Prometheus 后，仅非演示计算节点使用真实采集；演示节点始终使用模拟指标。真实资源映射、部署与实例生命周期仍使用已有适配层。

接口：`PUT /api/resources/{kind}/{resource_id}/context`，正文为 `{"scene_ids": ["communication_network_and_services"]}`；传空数组取消全部场景关联。`kind` 为 `image`、`compute`、`storage` 或 `network`。

同步保留已有真实资源的场景关联；真实资源与演示资源同名时创建单独记录，不覆盖演示来源。启动按固定 ID 补充缺失的示例数据，不重置用户已有模板和资源，不恢复已取消的场景关联。旧版种子数据在新库初始化时同样标记为演示；旧数据库中没有来源记录的数据保守显示“来源待核验”。

## 本地验证

后端：`cd backend` 后运行 `python -m unittest discover -s tests -v`。

前端：`cd frontend` 后运行 `npm ci`、`npm test` 和 `npm run build`。组件交互检查验证目录筛选、六份证据视图、资源关联保存、示例入口及场景切换时忽略旧请求；它不替代浏览器视觉验收。

需要与旧目录服务同时运行时，后端改用端口 8001；前端 PowerShell 执行：

```powershell
$env:API_PROXY_TARGET = 'http://127.0.0.1:8001'
npm run dev -- --port 5174 --strictPort
```

默认后端代理仍是 8000，不影响原启动方式。
